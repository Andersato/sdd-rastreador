# Tasks

Todos los comandos se ejecutan desde la raíz del repo con el Python del
entorno virtual (`.venv/bin/python`). La respuesta real de la API (1.5) la
proporciona el usuario: se pide al empezar, pero solo la tarea 3.7 depende de
ella; el resto avanza con fixtures escritas a mano.
